## 1. 安装与首次启动

下载 APK 后直接安装。  
如果系统提示未知来源应用，请在系统设置中允许当前浏览器或文件管理器安装应用。

首次启动后，建议先完成：

```text
1. 配置 API
2. 设置全局用户信息
3. 创建或导入角色卡
```

---

## 2. API 配置

进入：

```text
设置 → API 配置
```

点击添加配置后填写：

```text
配置名称
Base URL
API Key
模型名
```

### 预设

名称旁有「预设」按钮，可以一键填入常见服务商的 Base URL：

```text
DeepSeek
OpenAI
Gemini
SiliconFlow 免费
自定义
```

填入预设后仍需自己补上 API Key 和模型名。

### 测试连接与模型列表

填写完成后可以点击测试连接。测试成功后会尝试拉取该服务商可用的模型列表，供你直接选择；即使测试失败，也可以手动输入模型名。

### 管理多个配置

可以保存多个 API 配置。列表里每条配置右侧的菜单支持：

```text
编辑
设为当前
删除
```

当前生效的配置会作为聊天默认使用。没有配置或配置错误时，聊天通常无法回复。

### 常见 Base URL 示例

DeepSeek：

```text
https://api.deepseek.com
```

模型名示例：

```text
deepseek-chat
```

不同服务商的 Base URL 和模型名请以对应服务商文档为准。

### API Key 保存位置

API Key 使用 `flutter_secure_storage` 保存在本地设备。  
开发者不会收集、上传或托管用户 API Key。

## 3. 全局用户设定

进入：

```text
设置 → 用户设定
```

可以设置：

```text
用户头像
用户昵称（留空时默认显示「我」）
```

这个设定会作为默认用户信息。  
当角色卡没有单独用户覆盖设定，且系统卡没有启用主角设定时，会自动使用这里的全局用户设定。

需要更详细的个人简介，或想让某个角色以不同的用户身份与你互动时，可以在聊天页设置面板的「用户设定」里填写当前卡的用户覆盖设定（见第 10 节）。

## 4. 角色库

进入角色库后，可以看到所有角色卡。

### 新建 / 导入 / AI 转译

点击右上角 `+`：

```text
新建角色卡
导入角色卡（.llmcard / 图片角色卡）
AI 智能转译角色卡
```

「AI 智能转译角色卡」可以把其他平台的角色卡（SillyTavern、TavernAI、PNG 内嵌角色卡）自动转换成本应用的角色，转换完成后直接加入角色库。详见下方「AI 智能转译」。

### 选中角色卡

点击角色卡会选中它（卡片展开显示名字、标签和简介）。  
再次点击选中的角色卡会进入编辑页。  
点击卡片外的空白区域可以取消选中。

### 标签筛选

当角色卡设置了标签时，角色库顶部会出现标签筛选栏：

```text
[全部] [傲娇] [校园] [原创] ...
```

点击某个标签只显示带该标签的角色，点击「全部」恢复。标签在角色编辑页的「角色信息」里填写，多个标签用逗号分隔。

### 排序

点击排序图标可以选择：

```text
默认顺序 / 创建时间
按名称
```

长按排序图标可以切换正序 / 倒序。

### 进入聊天

选中角色卡后，点击右下角播放按钮进入聊天页。  
点击后按钮会先播放加载动画，等待封面和 UI 引擎就绪后平滑跳转。

### 导出角色卡

选中角色卡后点击导出按钮，可以选择：

```text
导出完整角色卡文件
导出角色卡图片
```

#### 完整角色卡文件

格式：

```text
.llmcard
```

这是稳定分享和迁移推荐格式。导出时可以勾选是否包含用户覆盖设定和绑定世界书。

#### 图片角色卡

格式：

```text
.llmchar.png
```

适合展示分享。  
通过聊天软件发送时请使用“原图”或“文件”方式，否则内部数据可能丢失。

### 删除角色

长按一张角色卡片进入删除状态（卡片变红、出现删除图标）。可以长按多张一起标记，标记后顶部会出现带数量的「批量删除」按钮，确认后一次性删除全部标记的角色。也可以点击单张卡片的删除图标单独删除。删除后不可恢复，请谨慎操作。

### AI 智能转译

选择要转译的第三方角色卡文件（PNG / JSON）后，可以：

```text
选择转译使用的 AI 配置（默认使用当前启用配置）
关闭 AI 只做规则转译（更快，不调用模型）
```

转译会自动完成四步流水线：

```text
规则转译 → AI 智能归类 → AI 理解界面（生成 UI 与状态栏字段）→ 检查精修
```

转译过程有进度提示且不可取消。完成后角色直接加入角色库，可正常编辑和聊天。

## 5. 角色卡编辑

角色卡编辑页是一个浮层表单，点击角色卡即可进入。可以设置：

```text
角色名称
简短描述
角色头像
角色卡封面
卡片类型
绑定世界书
状态栏字段
UI 拼装方案
文本着色规则
角色设定条目
开场白
角色信息
```

编辑页从上到下依次是：头像、名称、描述、卡片类型、封面、绑定世界书、状态栏与 UI 入口、文本着色、设定条目、开场白、角色信息。

### 未保存草稿

角色编辑页是浮层，点击外部空白就会关闭，改到一半很容易误关。  
现在退出时会静默保存草稿（有效 24 小时），下次进入同一张卡时弹出「发现未保存的修改」，可以选择恢复或丢弃。

### 人物卡

适合普通角色扮演对象。

常见条目包括：

```text
名称
与用户关系
身体数据
心理数据
背景数据
```

### 系统卡

适合世界、游戏、剧本、系统流等设定。

常见条目包括：

```text
系统名称
系统概要
系统详情
主角设定
剧情
```

如果系统卡启用了主角设定，则聊天时可自动使用主角设定作为用户默认设定。

### 设定条目

条目按「简单介绍」和「详细设定」分组，每个条目都有启用开关，可以展开内联编辑（固定条目以子字段形式编辑）。还可以添加自定义条目，自定义条目使用独立编辑页。

### 角色信息

角色信息区用于填写：

```text
标签（逗号分隔）
作者
版本
作者备注
历史后指令
```

- 标签会显示在角色库卡片上，并驱动顶部标签筛选栏。
- 历史后指令是放在对话最末尾的强约束指令（如「只用中文、不要旁白、保持角色」），支持 `{{char}}`、`{{user}}` 占位符，兼容酒馆 post_history_instructions。
- 这些信息默认不注入 Prompt（历史后指令除外），主要用于展示、筛选与资料保留。

## 6. 开场白

角色卡编辑页中可以添加多条开场白，点击某条可编辑内容，也可以插入本地图片（以 `<img>` 标签形式保存并随角色卡导出）。

如果当前角色没有任何聊天历史，进入聊天页时会自动插入第一条非空开场白。

如果已有聊天记录，后续新增或修改开场白不会自动插入到已有对话中。  
如需重新显示开场白，可以清空聊天历史。

在聊天页中，如果最新一条 AI 消息是开场白，可以在消息下方的图标里用左右箭头切换不同的开场白版本。

## 7. 世界书

世界书用于补充世界观、地点、人物、事件、规则等设定。

### 世界书条目

每个条目可以设置：

```text
条目名称
内容
触发关键词（支持中英文逗号、分号、换行分隔多个）
启用 / 停用开关
是否常驻
是否递归触发
注入位置（角色设定之前 / 之后）
注入优先级（数值越小越靠前）
```

### 触发逻辑

- 常驻条目会持续生效，不依赖关键词
- 关键词条目会根据最近对话命中情况触发
- 递归触发可以让已触发内容继续激活其他条目
- 停用的条目不参与触发
- 注入优先级数值越小排得越靠前，越靠前模型越重视

### 世界书封面

世界书卡片封面由程序生成：渐变色卡中央是词云，统计条目和关键词的出现频率，频率越高的词气泡越大。没有词汇时回退为首字标识。

### 导入 / 导出

世界书可以导出为：

```text
.llmworld.json
```

导入时会先显示预览，确认后才真正导入。  
导入角色卡时若带有世界书，会按内容自动去重：相同内容的世界书只保留一份并复用绑定。

## 8. 背景图库

背景图库支持：

```text
图片背景
纯色背景
渐变背景
```

### 预设背景与非预设背景

背景分为预设背景和自定义背景：

- 预设背景：内置的配色 / 渐变模板，可以在三页编辑器里调整颜色、渐变或上传图片，但不能删除。
- 非预设背景：新建或导入的背景，只可以改名称和场景设定，可以删除。

### 应用到聊天 / 主页

在聊天页设置面板或主页中选择背景时，会弹出背景选择器，左右翻看卡片，点击即应用。选择时若带有当前角色上下文，则该背景会绑定为这个角色的独立背景；否则作为全局背景。

图片背景可以导出为背景卡。  
背景卡保持原图比例，不会强制裁剪成 2:3。

导出位置：

```text
Download / LLM Project / Backgrounds
```

## 9. 聊天页

聊天页包含：

```text
顶部状态栏
聊天消息列表
底部输入区
角色切换入口
右侧设置面板
```

新聊天没有历史时，会自动插入第一条开场白作为首条角色消息。消息以 Markdown 渲染，支持图片、代码等格式；角色配置了文本着色规则时，台词、旁白等片段会按规则着色。

### 输入与发送

点击底部输入按钮展开输入框，输入后点击发送。输入框下方会实时估算 Tokens 消耗。

如果角色配置了场景 / 常驻 UI 组件，输入可能由场景组件接管；没有配置时使用底部原生输入框。

### 角色切换

聊天页底部（输入框上方）有一个角色名称胶囊，显示当前角色名。点击它会在屏幕下半部展开弧形角色轮盘：

- 左右滑动浏览角色卡
- 点击某张卡即可切换当前聊天对象，无需退出聊天页
- 输入框展开时胶囊会淡出，收起后恢复

### 消息操作

最新一条 AI 消息下方有一排功能图标：

```text
重新生成
继续回复
开场白切换（仅当消息是开场白）
多版本切换（重新生成后的历史版本）
```

- 重新生成：丢弃当前回复，让模型重新回复一次
- 继续回复：在当前回复末尾继续往下写
- 开场白切换：如果是开场白消息，用左右箭头切换不同开场白
- 多版本切换：重新生成的历史版本会保留，用左右箭头在版本间切换

用户消息支持：

```text
点击编辑
撤回（删除最近用户消息及后续回复）
```

- 点击用户消息气泡进入编辑，保存后替换该消息并重建后续回复
- 最新一条用户消息旁的「撤回」图标可删除这条消息及其后所有回复，常用于发错内容后回退

### 清空历史

聊天设置面板里提供「清空历史」，可以把当前角色的对话历史清空，并选择是否同时把用户设定重置为角色卡默认。清空后会重新插入开场白。

### 设置面板

在聊天页按住右侧边缘向左滑动打开设置面板，里面可以进入：

```text
当前角色用户设定
当前角色 Prompt 策略
背景设置
清空历史
Prompt 预览
```

## 10. 当前卡用户设定

在聊天页右侧设置面板中进入：

```text
用户设定
```

这里设置的是当前角色卡的用户覆盖设定，包括头像、昵称和详细设定，且可以随时「恢复默认」。

优先级为：

```text
当前卡用户覆盖设定
> 系统卡主角设定
> 全局用户设定
```

也就是说：

- 如果当前卡保存了用户覆盖设定，就使用覆盖设定
- 如果没有覆盖设定，但系统卡启用了主角设定，就使用主角设定
- 如果都没有，就使用全局用户设定

如果当前是系统卡，覆盖设定页还提供「保存为角色卡默认」，可以把当前设定写回系统卡的主角设定。

## 11. Prompt 策略

Prompt 策略控制最终发送给模型的系统提示结构，属于进阶功能。

### 全局默认策略

进入：

```text
设置 → Prompt 策略
```

这里配置的是全局默认策略，所有未开启单独策略的角色都会使用它。

可配置项：

```text
注入角色扮演规则（人物卡规则 / 系统卡规则文本）
注入连续性提醒
注入历史后指令
摘要设定注入间隔（0-12 个用户回合，0 关闭）
完整设定注入间隔（0-36 个用户回合，0 关闭）
世界书扫描深度（1-12，推荐 4）
```

规则文本支持 `{{char}}`、`{{user}}` 占位符（发送前替换为角色名和用户名）。滑动条与数字框都可以调整，超出推荐范围会提示可能影响 token 开销或设定保持效果。

### 角色单独策略

从聊天页设置面板进入 Prompt 策略时，是针对当前角色的版本：

- 默认情况下角色沿用全局策略
- 开启「当前角色使用单独 Prompt 策略」后，改动才只影响这个角色
- 可以随时「恢复使用全局策略」

### Prompt 预览

策略页右上角有眼睛图标，可以预览实际发送给模型的完整 System Prompt，包括：

```text
System Prompt 开头
对话历史
历史后注入（贴近模型回复的强约束指令）
估算 Tokens
```

各区块可以单独复制，也可以一键复制全部。如果角色表现不符合设定，先在这里确认期望的设定是否真的被注入。

## 12. 状态栏与文本着色

这两个是角色编辑页里的附属编辑器，入口在编辑页中部的「状态栏」与「文本着色」卡片上。

### 状态栏

状态栏在聊天页顶部显示一排玩法数值 / 文本字段（如 生命、好感、地点）。字段定义随角色卡保存；运行时当前值另存于会话副本，清空记录后回到初始值。

在状态栏字段页点击「添加字段」，每个字段可设置：

```text
字段名称
类型（数值 / 文本）
归属（玩家的属性 / 角色自己的属性 / 中立环境）
初始值
最小值 / 最大值（数值型）
```

- 归属决定注入 Prompt 时的主语（如「玩家的金钱」），帮助 AI 判断该加还是该减
- 数值字段由 AI 只返回增量、引擎负责计算并夹在范围内
- 聊天时展开状态栏，每个块顶部有小滑块可把它固定显示在长条的左 / 右侧

如果 UI 拼装里引用了还没创建的字段，状态栏页顶部会列出「界面里引用了 N 个还未创建的字段」，点击即可按界面组件的当前值创建，创建后回到 UI 拼装页自动完成绑定。

### 文本着色

文本着色页用正则表达式匹配消息片段并着色。每条规则可设置：

```text
规则名
启用开关
正则表达式（语法错误会红字提示）
颜色（固定色板或「沿用正文颜色」）
加粗 / 斜体
优先级（上下箭头调整，靠前的先占位）
```

顶部有实时预览框，可以粘贴实际文本查看效果。规则只影响显示、不会改写内容——发给模型和存档的始终是原文。没有配置过时使用内置默认规则。

## 13. UI 创作工作室

进入：

```text
设置 → UI 创作工作室
```

这是一个可视化搭建工具，用来制作自定义界面组件，可以理解成「搭积木」。它由三部分构成：**原子组件**（原材料）、**画布**（搭建区）、**联动器**（接线，让组件之间产生关联）。

### 原子组件分四类

左侧「原材料」区的原子按用途分四组：

1. **外观**（纯视觉，不产生数据）：面板、图片、线条
   - 面板：带形状 / 圆角 / 填充色 / 描边的容器，作为摆放其它元件的底面
   - 图片：显示图片，可设来源、缩放方式、形状、圆角
   - 线条：一条分割线，可设粗细、样式、方向、颜色
2. **显示**（展示数据，不接受输入）：文本、进度条、指示灯
   - 文本：显示文字，可用模板（`{{current}}` 等）引用来源数值实时更新
   - 进度条：数值条，可设最小 / 最大 / 当前值、形状（含胶囊、圆环）
   - 指示灯：会变色的状态灯，按传入值显示不同颜色
3. **交互**（玩家可操作）：输入框、下拉、滑块、开关、按钮
   - 输入框：玩家输入文字，可设占位、必填、多行、最大长度
   - 下拉：从选项里选一个，可设选项、展开方向、是否由输入控制
   - 滑块：拖一个数值，可设范围、步长
   - 开关：true / false 开关
   - 按钮：可点击触发事件的透明热区，可设单击 / 双击 / 长按
4. **逻辑**（后台件，运行时不显形）：联动器、计算节点、定时器
   - 联动器：建立 A→B 的连线协议
   - 计算节点：加减乘除、比较等运算，可多级串联
   - 定时器：按间隔持续触发，做持续变化的数值

### 工作台

- 左侧「原材料」区提供上述原子，长按拖入画布
- 画布是带网格的无限画布，支持撤销 / 重做（最多 100 步）、复制粘贴、多选删除、清空
- 选中元件后可以用 D-Pad 微调、编辑精确几何数值、调整图层顺序
- 页面会自动保存草稿，退出后重新进入可继续编辑

### 联动器协议

把「联动器」放到画布上，从一个组件的输出口拉线到另一个组件的输入口，就建立了一条协议。68 条协议按**用途**分成八组，接线时按「想让界面发生什么」来找：

- **① 点击触发（button）**：把「按钮被点了」接到目标。→ 面板按压反馈、开关翻转 / 强制开 / 强制关、清空输入框、重置滑块、启停 / 重置定时器、手动触发计算节点
- **② 状态控制（switch / indicator）**：用一个开/关或颜色状态控制别的组件。→ 显隐、使能、锁定、数值冻结、切换文案、定时器启停
- **③ 数值搬运（slider / progress / input / text）**：把数值搬到另一个组件。→ 滑块 → 进度条 / 文本、进度 → 文本、输入 → 进度条 / 滑块、文本取数 → 计算参数
- **④ 文字渲染（→ text）**：把各种值变成文字。→ 滑块 / 进度 / 下拉 / 定时器值、输入同步、开关文案、计算结果渲染
- **⑤ 条件判断（→ button / switch / indicator）**：根据内容或数值决定状态。→ 输入非空 / 校验通过才启用按钮、文本非空 / 匹配启用按钮、进度阈值启用按钮或开开关、输入校验或长度驱动指示灯、输入匹配 / 过滤下拉选项
- **⑥ 定时驱动（timer）**：让变化自动持续发生。→ 每次 Tick 翻转 / 开 / 关开关、进度加减、触发计算、数值显示文本
- **⑦ 数值计算（math_node）**：做多步运算。→ 结果渲染文本（含条件文案）、驱动进度条（含百分比 / 布尔跳满）、注入另一计算参数、多级串联
- **⑧ 联动全局**：
  - 配额分配（pool → allocation）：把组件当「可分配总量」，其它滑块 / 输入框从中分配点数（如属性点分配面板）
  - 数值求和（sum → display）：把多个数值加起来显示到一处

### 保存与复用

搭好的界面可以「保存为复合组件」存到 UI 模组库，并设置对外暴露的端口。保存的复合组件可以在角色 UI 拼装里直接拖入使用。

## 14. UI 模组库

进入：

```text
主页模块轨道 → UI 模组库
```

UI 模组库集中展示你保存的界面资产：

- 复合组件按设计时的原始比例展示，可直接在卡片里点击、拖动试用交互
- 每张卡片支持导出（`.llmui` 文件，保存到下载目录）和删除
- 右上角可导入其他 `.llmui` 文件

删除复合组件时，已经用到角色卡里的实例不受影响——组件在角色卡里是值拷贝，删除模板不会让已经摆好的界面变空。

## 15. 角色 UI 拼装

进入：

```text
角色编辑页 → UI 入口 → UI 拼装方案
```

给角色设计「会动的聊天界面」。每种 UI 类型只能有一个：

```text
开场白弹窗：首次进入聊天时全屏展现，玩家确认后销毁（适合角色设定确认、初始选项）
场景 UI：全屏接管整个聊天页，替代对话气泡（适合战斗界面、养成面板）
常驻 UI：浮在聊天上方，可折叠为悬浮球（适合好感条、状态指示器）
伴生 UI：嵌入最新消息气泡下方跟随滚动（适合评论区、记录面板）
```

场景 UI 与伴生 UI 互斥。选择类型后进入拼装画布：

- 在 PCB 上拖放元件，建立平级页 / 叠加页实现多页面切换
- 双击元件编辑「数据通道」——配置组件读写的字段、AI 读写策略、注入位置和提醒方式
- 多开场白时，每条开场白对应一个平级分支，可为不同开局设计不同界面或初始数据
- 保存后返回时会自动把绑定组件的初始值 / 量程同步回状态栏字段

保存后进入聊天页即可看到效果：开场白弹窗在首次进入时弹出、场景 UI 接管整屏、常驻 UI 浮在聊天上方（可长按拖动折叠）、伴生 UI 跟随最新消息。配置了场景 / 常驻 UI 时，输入可能由场景组件接管。

## 16. 备份与恢复

进入：

```text
设置 → 备份与恢复
```

可以导出完整备份：

```text
.llmbak
```

导出内容可以自定义，包括：

```text
角色卡
世界书
背景图库
图片资源
全局用户设定
当前角色用户覆盖设定
聊天记录
API 配置
API Key
Prompt 策略
排序和界面偏好
```

默认不导出：

```text
API Key
聊天记录
当前角色用户覆盖设定
```

因为这些可能包含隐私。勾选敏感项时，导出前会再弹一次提醒确认。

导出位置：

```text
Download / LLM Project / Backups
```

### 导入备份

恢复备份时有两种方式：

```text
合并导入：生成新 ID、不覆盖现有数据（推荐）
恢复导入：保留原 ID、同 ID 覆盖现有数据
```

导入前建议先导出一份完整备份。恢复会覆盖当前数据，请谨慎操作。导入完成后如果数据没有立即显示，可以退出页面重新进入刷新。

## 17. 资产导入说明

导入时不依赖文件扩展名，而是读取文件内部标识。  
如果文件不是 LLM Project 导出的资产，会提示无法识别。

### 常见导入失败原因

```text
文件不是 LLM Project 资产
文件被聊天软件压缩
图片不是原图
文件数据损坏
资产版本高于当前 App 支持版本
```

如果是图片角色卡或背景卡，请确认发送方使用了：

```text
原图发送
或
文件发送
```

## 18. 常见问题

### Q：为什么 API 连接失败？

请检查：

```text
Base URL 是否正确
API Key 是否正确
模型名是否正确
手机网络是否正常
App 是否允许联网
```

如果错误是：

```text
401 / 403
```

通常是 API Key 问题。

如果错误是：

```text
Failed host lookup
```

通常是网络、DNS 或联网权限问题。

---

### Q：为什么小米 / 澎湃 OS 顶部有黑框？

请在系统设置中找到本应用，将状态栏 / 刘海显示设置为：

```text
始终显示
```

---

### Q：为什么图片角色卡导入失败？

可能是图片被聊天软件压缩，导致内部数据丢失。  
请让对方选择：

```text
原图
或
以文件方式发送
```

---

### Q：为什么开场白没有显示？

开场白只会在当前角色没有任何聊天历史时自动插入。  
如果已有聊天记录，新增开场白不会插入到对话中间。

---

### Q：备份可以迁移到改包名后的版本吗？

可以。  
完整备份会导出数据库数据和图片资源，适合包名变化、换手机、重装 App 时迁移。

---

### Q：为什么检查更新提示「检查更新失败」？

「检查更新失败」表示网络异常、仓库不可达或读取版本信息失败，与「已是最新版本」是两回事。请检查网络（国内环境会自动尝试可直连的更新源），稍后重试。

---

### Q：UI 组件 / 状态栏为什么在聊天页不生效？

- 确认角色编辑页里已经保存了 UI 拼装方案和状态栏字段
- 每种 UI 类型只能有一个；如果历史数据里有同类型的多份，只有第一份会生效（列表里会标红提示）
- 场景 UI 与伴生 UI 互斥，两者不能同时存在
- 修改后重新进入聊天页查看效果

---

### Q：编辑角色卡误关后内容丢失了吗？

没有。角色编辑页退出时会静默保存草稿（有效 24 小时），下次进入同一张卡会弹出「发现未保存的修改」，选择恢复即可。

---

### Q：为什么我配了文本着色规则却不生效？

- 确认规则已启用，且正则语法没有错误（错误会在输入框下红字提示）
- 规则按从上到下的顺序生效，靠前的规则先占位，后面的规则不会覆盖已着色的部分
- 着色只影响显示，不影响发送给模型的内容
